# Contributing

Thanks for helping improve Aureus Quant.

1. Fork the repository or ask the owner to invite you as a collaborator.
2. Create a branch for your change.
3. Install dependencies with `npm ci`.
4. Run `npm run dev` to check the app locally and `npm run build` before submitting.
5. Open a pull request describing the change and any relevant screenshots.

Please do not commit credentials, private customer data, or unverified financial claims. The market display is a simulation, not a live feed.
